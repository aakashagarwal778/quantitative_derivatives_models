# Learning path

1. Start with `notebooks/01_pricing_foundations/`.
2. Move to lattice methods for discrete-time replication.
3. Continue into Monte Carlo and variance reduction.
4. Study PDE and ODE methods as continuous-time numerical pricing tools.
5. Move to Heston for stochastic volatility.
6. Add jumps with Merton jump-diffusion.
7. Explore local volatility and SABR as smile-consistent models.
8. Review calibration workflows and empirical preprocessing.
9. Finish with transform methods as an alternative pricing route.
