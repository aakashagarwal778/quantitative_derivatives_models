# Numerical methods map

- Closed form: Black–Scholes, some SABR approximations, perpetual American put formula
- Trees: binomial and trinomial lattices
- Monte Carlo: European pricing, variance reduction, Longstaff–Schwartz
- PDE / ODE: explicit finite differences, Crank–Nicolson, perpetual put ODE
- Fourier / transform: Heston pricing integration, Laplace-based pricing
